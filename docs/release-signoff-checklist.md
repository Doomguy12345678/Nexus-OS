# Release Sign-Off Checklist

## Engineering review

- [ ] Base platform selection is documented and justified.
- [ ] Build process is repeatable and logged.
- [ ] Update and rollback policy has been reviewed.
- [ ] Beta hardware matrix has been completed.
- [ ] Critical launch blockers are closed or accepted with mitigation.

## Security review

- [ ] Signing policy and key-handling procedure documented.
- [ ] SBOM and provenance generated for the beta candidate.
- [ ] Vulnerability review performed for third-party bundles.
- [ ] Installer flow reviewed for privilege and data-loss risks.
- [ ] Recovery flow reviewed for user-impact scenarios.

## Support review

- [ ] Supported hardware classes are published.
- [ ] Known limitations are documented.
- [ ] Release notes are complete and understandable.
- [ ] Escalation path and support owner are declared.
- [ ] User communication plan approved.

## Product review

- [ ] Real user cohort defined.
- [ ] Beta risk statement approved.
- [ ] Public-facing messaging does not overstate support claims.
- [ ] Exit criteria for the beta and next milestone are defined.
